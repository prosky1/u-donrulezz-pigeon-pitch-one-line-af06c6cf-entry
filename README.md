Entry for the make.fun bounty "Pigeon Pitch, One Line": the one-line elevator
pitch a city pigeon gives investors for its startup.

The program writes one line (100 characters) to `entry.txt` in the output
directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).

## Run it

```
node main.ts
```
